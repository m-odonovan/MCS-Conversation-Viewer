# MCS-Conversation-Viewer
Upload or copy the conversation JSON from Copilot Studio conversation into this tool and get a visual representation of the conversation. Helps you debug issues with conversations. Works best if enhanced transcripts are turned on in Copilot Studio.

## How to use
This is a single HTML file solution. Simply download the index.html file and run it. Then upload or copy conversation JSON into the tool and it will do the rest.
